# Claude Night for Typora

A warm dark Typora theme with editorial serif typography, soft ivory text, and terracotta accents.

## Features

- Deep charcoal canvas with warm, low-glare text colors.
- Georgia/Cambria serif typography with system fallbacks for Chinese text.
- Clear heading hierarchy, styled quotations and tables, and high-contrast code tokens.
- Matching dark styling for YAML front matter and math block editing.

## Installation

1. Download `claude-night.css` from this repository.
2. In Typora, open **Preferences → Appearance → Open Theme Folder**.
3. Copy the CSS file into the theme folder.
4. Restart Typora and choose **Claude Night** from the **Themes** menu.

The theme uses locally available system fonts and does not bundle external fonts.

## Compatibility

Designed and styled on Typora for Windows. The theme uses standard CSS and Typora's documented CodeMirror selectors; macOS and Linux presentation has not been separately checked.
